# 国际供应链行业研究

[完整看板](https://jamese5095.github.io/international-supply-chain-research/) · [六页结论概览](https://jamese5095.github.io/international-supply-chain-research/story/)

主导航：行业规模、区域流向、区域热力图、重点项目。

## 行业与研究方向

2025年子行业整体进口或出口≥500亿美元为规模工作线，形成13项商品产业重点与3项渠道观察。再以同口径单向金额占进出口合计≥60%确定主方向：进口研究来源，出口研究去向。整体接近均衡时，按具体产品或项目选择方向并明确范围。两条阈值均为本轮研究工作线，不是外部行业标准。

本轮覆盖全部13项规模重点：进口方向为半导体、工业原材料、食材供应商、制药核心；出口方向为电子零部件、消费电子家电、乘用车、汽车零部件、机械设备、电力设备、家居建材、鞋服、诊疗器械核心。医疗器械整体59.2%未达60%，按具体产品出口方向研究。制药整体接近均衡，仅HS3001—3004核心品目进口主导。13项全部提供国别流向，但核心品目金额不等同整体规模；不按全国用途系数分配国别金额。

摄像设备、增材制造设备与玩具作为项目补充方向单列；主视图每次仅显示一个方向，反向贸易在完整数据内展开。原数据共16个商品范围、25个已查询原始方向，单位亿美元。芯片使用独立2025年HS8542查询，含集成电路零件，不含全部半导体设备和材料；其他亚洲490与中国156回流保留统计范围。排行排除中国回流，全球分母保留回流。

## 数据与页面

- `data.json`：原29项规模及145个客户名册条目，原样保留。条目未经跨行业集团去重。
- `selection.js`：规模工作线、主方向工作线、研究方向及项目补充定义。
- `flows-data.js`、`downloads/flows-2025.json`：国别金额和查询记录；原新增36次查询及本次2次芯片查询均低于500条上限，全球与伙伴合计核对通过。原XLSX保留原研究范围。
- `directional.js`：单向来源／去向图及方向依据。
- `trade-heatmaps.html`：区域热力图及大区品类详情，替换原企业布局主导航；原独立企业布局页已删除。
- `strategy.js`、`project-evidence.js`：8家企业、项目依据及附着项目的能力方案。境外、区域、单国与参会数据分别标注范围，不折算当地货量或顺丰收入。
- `story/`：概览第二页确定研究方向，第三页呈现芯片来源、消费品去向和欧洲药源；客户、资源与能力方案在后续页展开。

## 区域贸易热力图

[独立上下双图](https://jamese5095.github.io/international-supply-chain-research/trade-heatmaps.html?v=20261102-regions)：出口蓝色、进口红色，共用固定金额分档；13个重点子行业可切换，区域金额和行业贡献同步更新，无缩放和国家下钻。

`downloads/trade-regions-2025.json`包含原始伙伴逐行业金额、13项商品篮子与双向来源、62个互不重叠HS编码，以及原BG总览的10区域映射。区域内统一着色，撤销旧版国别等额均摊。Comtrade 490对应中国台湾，归东亚；东南亚按原BG的11国范围汇总。跨BG区域的未拆分统计项单列。

出口香港金额1,213.88亿美元（本范围11.9%）从东亚需求热度中单列为后续去向待分配，未推定其全部转口或全部本地留用。香港官方API拒绝转口同时按原产地和HKHS商品分类查询，Comtrade同商品RX及第二伙伴156查询返回0条；因此未套用香港全商品转口率。页面保留限制说明、官方来源及后续分配方法。中国大陆进口回流662.17亿美元另列。

区域金额、香港待分配、回流及其他未分配之和与全球总额一致，13项逐行业双向金额核对通过。完整范围、区域成员和原始来源在图下展开。原29行业规模与主看板流向数据未改写。

## 区域品类细则页

全球热力图点击区域或排名进入`trade-heatmaps.html#region/europe/all`等区域路由。区域页包含定位地图、双向规模及全球区域占比、13项进口出口镜像柱图、三种排序、HS商品金额与占比、区域内主要伙伴及集中度。商品明细由62个HS编码的124次原始方向查询计算，全部13项×10区域×双向合计与既有区域金额逐项核对（误差低于0.01亿美元）。新增40个查询，复用84个已有查询；来源及哈希位于`downloads/trade-region-products-2025.json`。

地图区域标签移除白色底框，悬停强调区域形状；点击打开区域详情。返回全球页保留原行业筛选和滚动位置。区域页继续进入重点项目与能力方案。香港后续去向待分配额仍单列，未分配至区域商品需求。

区域热力图已成为主导航第三模块。原独立企业布局页面删除，行业流向与重点项目中的相关入口改接热力图或大区品类详情；旧`#layout`及`#explore/enterprise`路由转入热力图。客户与重点项目研究资料保留。

## 展示简化与数据复用

移除主看板、国别方向、全球区域与大区细则的全部CSV下载入口、事件及序列化代码。图表直接用于网页查看。`research-data.js`统一复用版本化数据快照：当前页面内使用内存缓存，同一标签页跨页面使用sessionStorage；相同版本只首次读取JSON，底图由两个页面共享。缓存不可用时回退到浏览器HTTP缓存。更新研究JSON时须同步提升该文件中的snapshot版本。取消重复的“正在载入”文字，错误时仍提供明确反馈。

## 出口与进口能力建设

区域出口/进口图分别进入`capability-export.html`与`capability-import.html`，每页5项建设建议。区域细则保留项目入口，并增加两种能力入口；region/sub参数用于关联提示，hash可分享具体展开项。

两页共用`capability-content.js`、`capability-planning.js`与`capability-planning.css`。能力细则包括建设内容、位置、贸易背景、适用目标客户、国内可复用基础、海外新增、建设顺序、服务边界及投入条件。公开客户仅链接现有项目；行业材料只采用概括内容，不上传原件或内部经营指标。

金额继续通过`ResearchData.load('regions',...)`复用原区域数据，11个贸易指标已按同方向/区域/子行业/kind=region核对。能力间金额可能重复，不加总为机会市场。半导体设备无现有篮子对应额，单列客户项目延伸。能力页不加载底图、HS明细或完整客户数据，也无新增下载入口。

验证：JavaScript语法检查、11项金额核对通过；浏览器验证两图入口、进口返回定位、欧洲区域上下文、单卡展开与深链、390px无横向溢出和现有区域明细。研究JSON与缓存snapshot保持原版本。来源站点可用性及网络故障/禁用存储场景未重新逐项验证。

能力建设现已作为与区域热力图同级的主导航入口，内部切换出口与进口两页；全球热力图和区域详情的能力入口继续保留。重点项目仍保留原路由和导航，跨站大客户联动暂为设计建议，未宣称已实现。
