# 国际供应链行业研究

[看板](https://jamese5095.github.io/international-supply-chain-research/) · [六页结论概览](https://jamese5095.github.io/international-supply-chain-research/story/)

主导航：行业规模、区域流向、企业布局、重点项目。

- 行业规模：29项净额排行、重点方向进口出口镜像图。
- 区域流向：8个子行业、16个方向的同商品范围进出口图；前六境外伙伴、其他伙伴、完整排行、CSV及原始查询。
- 企业布局：`enterprise-layout.html`复用原六行业看板源代码，保留行业、区域、国家、企业、项目与来源、返回状态；隐藏原BG策略及独立能力模块。国家、区域及全球范围保持原样。
- 重点项目：8家企业按越南、欧洲、日本分组；数字保留时间、地域、背景或项目范围，能力建议附着于项目详情。

`strategy.js`为概览及本体共用的企业与能力方案；`project-evidence.js`保存8家企业公开证据及机会判断；`flows-data.js`与`downloads/flows-2025.json`保存流向金额与来源。原`data.json`及29项规模没有改写。

## 数据范围

2025年中国贸易，金额亿美元。鞋服流向沿用首页商品范围，其余为核心品目，不能与全子行业金额等同或跨行业相加。流向覆盖鞋服、家电及音视频、电子零部件、制药、工程机械及配件、增材制造设备、摄像设备、玩具。新增36次2025查询均低于500条预览上限，逐查询及汇总核对全球与伙伴金额。

企业经营背景不直接转为当地货量或顺丰可承接收入：影石境外收入为全球境外范围，泡泡玛特亚太收入不是日本收入，BYD西班牙销量不外推全欧洲；三一峰会参会国家不等于服务覆盖。项目均为建议拓展业务，现有承运关系按公告具体地域及业务范围保存。

原规模XLSX与首批六方向国家XLSX继续供下载；完整16方向数据以新增JSON及逐方向CSV提供。企业原资料保留145个名册条目，未经跨行业集团去重；案例数不代表货量。

## 行业筛选与流向覆盖

`selection.js`维护500亿美元研究工作线、5项规模主线与3项项目延伸。规模按2025年子行业整体进口或出口较大值判断：13项商品产业重点、3项渠道观察。本轮流向从其中5项开始，另按影石、拓竹、泡泡玛特项目延伸3项低于规模线的子行业；8项不是按规模门槛筛出的完整名单。页面保留13项金额及覆盖对照，核心品目不用于重新判断整体规模门槛。首页第二张图、区域流向、概览第二页同时展示这一口径。
