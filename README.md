# 国际供应链行业研究

[打开 GitHub Pages 看板](https://jamese5095.github.io/international-supply-chain-research/)

基于中国2025年进出口数据，从六行业规模筛选深入到产品、国家、客户线索与海外能力验证。

## 页面与数据

- 首页：29子行业净额排行、13个商品／产业方向与3个渠道观察项的进口出口镜像图。
- 子行业详情：整体金额、估算口径、情景范围及产品与国家研究。
- 首批六方向：服装鞋帽出口、家电及音视频核心出口、电子零部件核心进出口、制药核心品目进出口。
- 客户与案例：145个名册条目，保留原有项目、地域、时间状态及来源。
- 能力验证工作台：需求验证与建设条件；尚未确认为已验证商机或投资方案。
- 页面提供对应的规模研究与国别研究XLSX下载。

## 口径

基准年2025，研究更新2026-11-01，金额单位亿美元。29项存在商品、用途和渠道交叉，不能加总。净额表示出口减进口。情景估算与可识别下限均在页面说明。国家研究除服装鞋帽外采用核心品目范围，不直接等于首页全部子行业金额。

原客户条目尚未进行跨行业集团去重。历史、规划、区域共用项目保留原范围，贸易伙伴不直接代表最终消费地或实际起运地。客户关联资料不能证明贸易贡献或顺丰可承接关系。

## 本地运行

```sh
python3 -m http.server 8765 --directory docs
```

打开 http://localhost:8765 。双击HTML不能通过fetch加载JSON，需使用HTTP服务。

## 更新与发布

`docs/`是GitHub Pages发布目录；使用main分支的/docs目录部署。`docs/data.json`是前端发布快照，`docs/downloads/`包含同批次研究工作簿。更新时同步维护JSON和XLSX，验证金额、覆盖范围与数据版本后提交。没有前端编辑或自动导入功能。

原地图看板位于`docs/case-atlas.html`，其中的本地编辑不会回写本看板数据。

`validation.json`记录数据一致性检查。第三方脚本与地图许可保存在`docs/vendor/`。本仓库未对顺丰标识或第三方材料授予额外许可。
