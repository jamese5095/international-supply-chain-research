# 国际供应链行业研究

[完整看板](https://jamese5095.github.io/international-supply-chain-research/) · [六页结论概览](https://jamese5095.github.io/international-supply-chain-research/story/)

主导航：行业规模、区域流向、企业布局、重点项目。

## 行业与研究方向

2025年子行业整体进口或出口≥500亿美元为规模工作线，形成13项商品产业重点与3项渠道观察。再以同口径单向金额占进出口合计≥60%确定主方向：进口研究来源，出口研究去向。整体接近均衡时，按具体产品或项目选择方向并明确范围。两条阈值均为本轮研究工作线，不是外部行业标准。

本轮覆盖全部13项规模重点：进口方向为半导体、工业原材料、食材供应商、制药核心；出口方向为电子零部件、消费电子家电、乘用车、汽车零部件、机械设备、电力设备、家居建材、鞋服、诊疗器械核心。医疗器械整体59.2%未达60%，按具体产品出口方向研究。制药整体接近均衡，仅HS3001—3004核心品目进口主导。13项全部提供国别流向，但核心品目金额不等同整体规模；不按全国用途系数分配国别金额。

摄像设备、增材制造设备与玩具作为项目补充方向单列；主视图每次仅显示一个方向，反向贸易在完整数据内展开。原数据共16个商品范围、25个已查询原始方向，单位亿美元。芯片使用独立2025年HS8542查询，含集成电路零件，不含全部半导体设备和材料；其他亚洲490与中国156回流保留统计范围。排行排除中国回流，全球分母保留回流。

## 数据与页面

- `data.json`：原29项规模及145个客户名册条目，原样保留。条目未经跨行业集团去重。
- `selection.js`：规模工作线、主方向工作线、研究方向及项目补充定义。
- `flows-data.js`、`downloads/flows-2025.json`：国别金额和查询记录；原新增36次查询及本次2次芯片查询均低于500条上限，全球与伙伴合计核对通过。图表提供逐方向CSV；原XLSX保留原研究范围。
- `directional.js`：单向来源／去向图及方向依据。
- `enterprise-layout.html`：复用原六行业看板源码，保留区域、国家、客户、案例、来源和返回状态；隐藏原BG策略与独立能力模块。
- `strategy.js`、`project-evidence.js`：8家企业、项目依据及附着项目的能力方案。境外、区域、单国与参会数据分别标注范围，不折算当地货量或顺丰收入。
- `story/`：概览第二页确定研究方向，第三页呈现芯片来源、消费品去向和欧洲药源；客户、资源与能力方案在后续页展开。

## 图1计算方法与来源

图1下方展示五类方法：10项商品篮子、2项行业发布统计、10项用途分摊、6项渠道终端温控情景、1项可识别下限。可切换全部29项查看进口、出口、净额、计算链与原始来源链接，并展开逐商品系数和参数。`calculation-data.js`及`downloads/calculation-methods-2025.json`从原校准模型映射，底数来源与研究假设分列，图1金额没有改动。
